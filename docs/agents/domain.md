# Domain docs

Single-context repo.

- `CONTEXT.md` at the repo root is the glossary and the only source of domain vocabulary. Write code, issues, tests and commits in its terms.
- `docs/adr/` holds accepted decisions. Read the ADRs covering an area before changing it; an ADR that contradicts a plan wins until it is superseded.
- `docs/sources.md` lists the Sources the analyzer may collect from, and why everything else is excluded. Adding a Source means editing that file first.
